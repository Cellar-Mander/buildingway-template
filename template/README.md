# My Plugin Display Name

My plugin punchline.

A [Dalamud](https://github.com/goatcorp/Dalamud) plugin for Final Fantasy XIV.

## Installing

In game, open `/xlsettings` → Experimental, add this to Custom Plugin Repositories and save:

```
https://raw.githubusercontent.com/my-plugin-owner/my-plugin-repo/main/repo.json
```

Then find My Plugin Display Name in `/xlplugins` and install it.

## Using it

`/myplugin` opens the settings.
